== Legacy Terminology Identifiers

New data should use URIs as the value of `TERMINOLOGY_ID`, as described in the {openehr_base_types}#_terminology_identifiers[BASE Base Types specification^]: for example `http://snomed.info/sct` instead of `SNOMED-CT`. Data created before this recommendation uses short names, such as `SNOMED-CT` or `ICD-10`, which remain valid as legacy identifiers.

The conversion table below maps these legacy short names to the code system URIs listed in the HL7 https://terminology.hl7.org/en/external_code_systems.html[External Code Systems^]. Platforms use it to treat a legacy short name and its URI as the same terminology, e.g. so that an AQL query using the URI also matches data recorded with the short name. The table maps the name part only, so a version in brackets is not translated. Stored identifiers are not rewritten. The table is published as a {hl7_fhir}/conceptmap.html[FHIR ConceptMap^] in the {openehr_terminology_resources}[openEHR `specifications-TERM` repository^], file `computable/FHIR/conceptmap-legacy_terminology_ids.xml`. The source codes are the legacy short names and the target codes are URIs.
